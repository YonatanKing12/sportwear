# קטלוג המוצרים של SportWear

כאן עובר כל מוצר בדרך מהקישור ששלחתם ועד טיוטה בחנות.

## איך זה עובד

1. **אתם שולחים קישורים** לעמודי מוצרים אצל הספק או היבואן, אחד או הרבה.
2. **סוכן האיסוף** (`product-scout`) קורא כל עמוד, בונה ממנו קובץ מוצר מסודר ושומר אותו ב-`incoming/`.
   הסוכן לא נוגע בחנות.
3. **עוברים יחד על הקבצים:**
   - מחירים וכמויות במלאי
   - שאלות פתוחות
   - אישור שמותר להשתמש בתמונות

   מה שמאושר עובר ל-`ready/`.
4. **סוכן התרגום** (`catalog-translator`) מוסיף אנגלית וערבית.
5. **סוכן היצירה** (`product-publisher`) יוצר את המוצרים בחנות **כטיוטות בלבד**, ומעביר את הקבצים ל-`published/`.
6. **אתם עוברים על הטיוטות בניהול החנות.** מוצר עולה לאוויר רק כשאתם מאשרים במפורש.

## התיקיות

| תיקייה | מה יש בה |
| --- | --- |
| `incoming/` | קבצים חדשים מהסוכן, מחכים לבדיקה |
| `ready/` | קבצים שאושרו, מוכנים ליצירה בחנות |
| `published/` | מוצרים שכבר נוצרו בחנות כטיוטה, כולל המזהים שלהם ב-Shopify |
| `images/` | תמונות לבדיקה מקומית בלבד. התיקייה לא נשמרת ב-git |

## הקבצים המשותפים

| קובץ | תפקיד |
| --- | --- |
| `product.schema.json` | המבנה המדויק של קובץ מוצר |
| `taxonomy.json` | ענפים, ליגות, קבוצות, סוגי חולצה, מידות, ושמות בעברית, אנגלית וערבית |
| `pricing.json` | כללי המחיר. **רק אתם קובעים מחירים.** מחיר חסר גורם לסוכנים לעצור ולשאול |
| `metafields.json` | השדות המותאמים בחנות (קבוצה, ליגה, עונה, טבלת מידות). הם קיימים בחנות, והמזהים ב-`store-setup.json` |
| `classification.json` | איך שם המוצר בעברית הופך לתגיות: קבוצה, ליגה, עונה, סגנון, שחקן, ומילות חיפוש. כולל את השמות בעברית, אנגלית וערבית |
| `store-setup.json` | מה קיים בחנות: הקטגוריות (עם הכללים שלהן), התפריטים, הדפים והמזהים |

## קטגוריות ותגיות

כל קטגוריה באתר היא קטגוריה חכמה: Shopify מכניס אליה מוצרים לפי התגיות שלהם. לכן מוצר חדש מופיע
בקטגוריות הנכונות ברגע שיש לו התגיות הנכונות.

- **התגיות:** `sport:`, `league:`, `team:`, `season:` (כדורגל בלבד), `style:retro|city-edition|special`,
  `player:` ושם השחקן בעברית, `audience:adult|kids|women`. הכללים והשמות נמצאים ב-`classification.json`.
- **מילות חיפוש:** לכל מוצר יש גם תגיות רגילות עם שם הקבוצה, הליגה והשחקן באנגלית ובערבית, ומילים נרדפות
  (גופייה, jersey, قميص, קפוצון, hoodie…). הן קיימות רק כדי שהחיפוש באתר ימצא את המוצר בכל שלוש השפות.
  התבנית לא מציגה תגיות. אל תוסיפו מסנן "תגית" באפליקציית Search & Discovery, כי הוא יציג את כולן.
- **הסקריפט `scripts/catalog/classify.mjs`** מחשב את התגיות לכל המוצרים ומדפיס מה להוסיף ומה להסיר. הוא לא
  כותב לחנות. כך מריצים אותו:
  1. מייצאים את המוצרים לקובץ JSONL עם `bulkOperationRunQuery` על
     `products { id handle title productType tags }`, ומורידים את הקובץ.
  2. `node scripts/catalog/classify.mjs products.jsonl --out plan.json`
  3. עוברים על מה שלא סווג ועל ההערות. תיקון לשם מוצר מסוים נכנס ל-`overrides` ב-`classification.json`.
  4. מחילים את התוכנית עם `tagsAdd` ו-`tagsRemove`, ורושמים כל שינוי ב-`published/`.

  הרצה על חנות מעודכנת מחזירה 0 שינויים.
- **היומן:** `published/classification-2026-09-26.json` מתעד לכל מוצר את התגיות שהיו לו, ומה נוסף ומה הוסר,
  כך שאפשר לבטל כל שינוי.

## ייבוא מהספק jerseyxie

המוצרים החדשים מהספק jerseyxie (Yupoo) עוברים מסלול משלהם: בוחרים לכל מוצר את התמונות הנכונות מתוך האלבומים
של הספק, מכינים צילומי סטודיו, בונים את קבצי המוצר עם סקריפט, ויוצרים אותם כטיוטות. הפירוט המלא, כולל
הטעויות הנפוצות בכותרות של הספק, נמצא ב-`sources/jerseyxie/README.md`.

## מה עוד פתוח

- מחירים לגופיות ולמכנסי כדורסל חדשים. בכדורגל המחירים נקבעו: ₪120 לחולצה למבוגרים ו-₪99 לסט ילדים.
- טבלת המידות של המוצרים שיובאו קודם (אתם שולחים).
