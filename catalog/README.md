# קטלוג המוצרים של SportWear

כאן עובר כל מוצר בדרך מהקישור ששלחתם ועד טיוטה בחנות.

## איך זה עובד

1. **אתם שולחים קישורים** לעמודי מוצרים אצל הספק או היבואן, אחד או הרבה.
2. **סוכן האיסוף** (`product-scout`) קורא כל עמוד, בונה ממנו קובץ מוצר מסודר ושומר אותו ב-`incoming/`.
   הסוכן לא נוגע בחנות.
3. **עוברים יחד על הקבצים:**
   - מחירים וכמויות במלאי
   - שאלות פתוחות
   - אישור שמותר להשתמש בתמונות

   מה שמאושר עובר ל-`ready/`.
4. **סוכן התרגום** (`catalog-translator`) מוסיף אנגלית וערבית.
5. **סוכן היצירה** (`product-publisher`) יוצר את המוצרים בחנות **כטיוטות בלבד**, ומעביר את הקבצים ל-`published/`.
6. **אתם עוברים על הטיוטות בניהול החנות.** מוצר עולה לאוויר רק כשאתם מאשרים במפורש.

## התיקיות

| תיקייה | מה יש בה |
| --- | --- |
| `incoming/` | קבצים חדשים מהסוכן, מחכים לבדיקה |
| `ready/` | קבצים שאושרו, מוכנים ליצירה בחנות |
| `published/` | מוצרים שכבר נוצרו בחנות כטיוטה, כולל המזהים שלהם ב-Shopify |
| `images/` | תמונות לבדיקה מקומית בלבד. התיקייה לא נשמרת ב-git |

## הקבצים המשותפים

| קובץ | תפקיד |
| --- | --- |
| `product.schema.json` | המבנה המדויק של קובץ מוצר |
| `taxonomy.json` | ענפים, ליגות, קבוצות, סוגי חולצה, מידות, ושמות בעברית, אנגלית וערבית |
| `pricing.json` | כללי המחיר. **רק אתם קובעים מחירים.** מחיר חסר גורם לסוכנים לעצור ולשאול |
| `metafields.json` | התכנון של השדות המותאמים בחנות (קבוצה, ליגה, עונה, טבלת מידות). עוד לא נוצרו בחנות |

## מה צריך לפני שיוצרים את המוצר הראשון

- להחליט על כל המחירים ב-`pricing.json`, ועל הסכום שממנו המשלוח חינם.
- להפוך את עברית לשפת ברירת המחדל בחנות, ולהוסיף אנגלית וערבית.
- לאשר את יצירת השדות המותאמים מתוך `metafields.json`.
