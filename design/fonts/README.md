# Theme fonts

All five families are licensed under the SIL Open Font License 1.1 and were downloaded from
Google Fonts on 2026-09-25 as woff2 subsets (`google-fonts.css` is the source CSS, `fonts.json`
the subsets used). The files live in `assets/font-*.woff2` and are declared in `snippets/fonts.liquid`.

| Family | Use | Subsets in the theme |
| --- | --- | --- |
| Anton | Display, Latin | latin, latin-ext |
| Karantina (700) | Display, Hebrew | hebrew |
| Changa (800) | Display, Arabic | arabic |
| Heebo (variable 400-800) | Body, Hebrew + Latin | hebrew, latin, latin-ext |
| Noto Sans Arabic (variable 400-800) | Body, Arabic | arabic |

OFL text: https://openfontlicense.org
